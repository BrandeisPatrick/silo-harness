Silo Harness

The self-improving agent harness.

For your Mac, in the style of Claude Code.

Dreaming reads your past sessions and proposes skills, memory and mods, and you keep what helps. Ask the agent for a mod and it builds one.

Download for macOS View on GitHub

For Apple silicon. MIT licence.

It gets better the more you use it

Silo Harness adapts to how you work, and you decide what sticks.

  1. Work

    You work with the agent, session by session.

  2. Dream

    Once a day, or when you ask, a dream reads your recent sessions.

  3. Keep what helps

    It proposes skills, memory and mods for you to apply or dismiss.

  4. Start the next session better

    New sessions begin with what you kept.

Dreaming

Once a day at a time you set, or when you ask, Silo Harness reads a project's recent sessions and proposes skills, mods and memory (lines for the project's instructions file). Each proposal quotes your own words and links the sessions it came from.

  • Approve, Auto or Plan mode, and anything applied can be reverted.
  • The daily dream is off until you turn it on.
  • A dream sends parts of past conversations to the model you configured.

Mods

Everything beside the chat is a mod: panels in the rail, tabs in the side pane, looks, themes, slash commands, and hooks that act before and after the agent's actions. Ask the agent for one and it writes it, then a card in the chat offers to turn it on.

  • Folders of web files with a documented protocol, reloaded when a file is saved.
  • Each mod declares its permissions, and you grant them when you turn it on.
  • The panels the app ships with are mods too, so yours can do what they do.

What it does

Made for reading

One calm column of text, and tool activity folded into a single quiet line that opens to every row.

Sessions side by side

Several sessions run at once, with sub-sessions and forks nested under the session they came from. Any session can find another by its name.

You decide what runs

Permission modes, approval cards, plan mode and rewind, as in Claude Code. Auto mode blocks only risky actions, with a reason.

Looks

A mod can restyle the conversation or the chat bar and bring a background. Hyperspace, a bundled set, jumps to lightspeed while the agent works.

Also

  • Local first

    Runs on qwen3:8b through Ollama, and nothing leaves your Mac. Built for small context windows: compaction, a context breakdown and a tool set sized to the model.

  • Nothing is lost

    An append-only history log survives crashes, rewinds and compactions. Deleted sessions go to a trash for 30 days.

  • Images in replies

    The model shows a screenshot or a chart inline, and tool rows carry thumbnails.

  • Remote control

    Follow a session and answer its approval cards from your phone. Off until you turn it on.

  • Settings

    One control per row, applied as you change it, and searchable.

  • Standard extensions

    MCP servers, skills (SKILL.md), project instructions (AGENTS.md, CLAUDE.md) and settings.json.

Get started

  1. Download the app

    From the latest release. It isn't notarized yet: on first launch, open it once, then allow it in System Settings → Privacy & Security → Open Anyway.

  2. Give it a local model

    Terminal
    brew install ollama && ollama serve &
ollama pull qwen3:8b

    Or a hosted one: Settings → Model → Gateway takes any OpenAI-compatible endpoint, such as Anthropic's or Portkey's, with your key.

  3. Or any other service, set up by your coding agent

    Silo Harness works with any OpenAI-compatible service: OpenRouter, Portkey, OpenAI, Anthropic, Groq, LM Studio or a gateway of your own. It is all in one file, and the app has a command for it, so a coding agent such as Claude Code can do the setup for you:

    Terminal
    silo provider add openrouter --type openrouter --model anthropic/claude-sonnet-4.5 --use
silo provider test

    The command is in the app at Silo Harness.app/Contents/Resources/bin/silo. See how to configure it.

  4. Or run it from source

    Terminal
    git clone https://github.com/BrandeisPatrick/silo-harness.git && cd silo-harness
npm install && npm start

Make it yours

A mod is a folder of web files. This one counts the words the assistant writes, in two files.

mod.json
{ "protocol": 1, "id": "word-count", "name": "Word count", "version": "0.1.0",
  "permissions": ["session:read"],
  "contributes": { "views": [{ "id": "main", "title": "Word count",
                               "entry": "panel.html", "seat": "rail" }] } }
panel.html
<link rel="stylesheet" href="/@harness/harness.css">
<div class="h-row">
  <span class="h-label">Assistant words</span><span class="h-value" id="n">0</span>
</div>
<script src="/@harness/harness.js"></script>
<script>
  let words = 0;
  harness.on('message.assistant', (m) => {
    words += (m.text.match(/\S+/g) || []).length;
    document.getElementById('n').textContent = words;
  });
</script>

Put them in ~/.silo-harness/mods/word-count/, turn the mod on, and the panel is in the rail. Or ask the agent: “make a mod that shows …”.
